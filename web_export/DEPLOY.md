# Web版本部署指南

## 免费部署平台推荐

### 1. GitHub Pages（推荐）
1. 创建GitHub仓库
2. 将web_export文件夹上传
3. 在仓库设置中启用GitHub Pages
4. 获取分享链接

### 2. Netlify
1. 访问 https://netlify.com
2. 拖拽web_export文件夹到上传区域
3. 自动生成分享链接

### 3. Vercel
1. 访问 https://vercel.com
2. 导入项目并部署
3. 获取分享链接

## 微信分享步骤
1. 将游戏部署到上述任一平台
2. 获取游戏链接
3. 复制链接通过微信发送给朋友
4. 朋友点击链接即可直接游玩

## 注意事项
- 确保所有文件（index.html、README.md等）都正确上传
- 首次部署可能需要几分钟时间生效
- 定期更新游戏内容后需要重新部署
