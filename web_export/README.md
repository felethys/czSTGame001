# 太空文字放置游戏 - Web试玩版

## 游戏简介
这是一个太空题材的文字放置游戏，玩家可以派遣飞船去不同星区进行探索和资源收集。

## 如何游玩
1. 直接打开 `index.html` 文件开始游戏
2. 或者通过部署后的链接访问游戏

## 游戏特色
- 无需安装，直接在浏览器中游玩
- 自动保存游戏进度
- 支持多种星区探索
- 丰富的任务和事件系统

## 技术说明
- 使用Godot 4.7引擎开发
- 导出为WebAssembly版本
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）

## 部署说明
将整个web_export文件夹上传到以下任意平台：
- GitHub Pages（免费）
- Netlify（免费）
- Vercel（免费）
- 或其他静态网站托管服务

## 注意事项
- 首次加载可能需要一些时间
- 游戏需要稳定的网络连接
- 建议使用现代浏览器获得最佳体验

## 当前状态
**注意**：当前版本为演示版本，完整的游戏需要通过Godot导出WebAssembly版本。此版本主要用于展示游戏界面和说明。
